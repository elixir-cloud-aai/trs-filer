TRS-Filer is being deployed!
{{- if not (or .Values.trs_filer.ingress.enabled $route) }}

WARNING: Neither an Ingress nor an OpenShift Route (the cluster serves none)
exposes the app. The Ingress is off by default, as the API has no
authentication: restrict POST, PUT and DELETE (see below), then set
`trs_filer.ingress.enabled: true`, or expose the app's Service
(`{{ .Values.trs_filer.appName }}`, port 8080) yourself.
{{- end }}

WARNING: The API has no authentication. Anyone who can reach it can register,
replace and delete tools and tool classes. Allow POST, PUT and DELETE only
from trusted clients, at the ingress controller (`trs_filer.ingress.annotations`)
or a proxy in front of it; see "Ingress" in the chart's README.

Once deployed:

  1. Access the API via {{ $scheme }}://{{ .Values.host_name }}/ga4gh/trs/v2/

     To test the connection, you can run:

       curl -X GET "{{ $scheme }}://{{ .Values.host_name }}/ga4gh/trs/v2/service-info" -H "Accept: application/json"

  2. Access the Swagger UI via {{ $scheme }}://{{ .Values.host_name }}/ga4gh/trs/v2/ui
{{- if eq $scheme "http" }}

  The URLs use http, as the chart serves no TLS; if a proxy in front of the
  cluster terminates TLS, use https instead.
{{- end }}
