TRS-Filer is being deployed!

WARNING: The API has no authentication yet (see
https://github.com/elixir-cloud-aai/trs-filer/issues/7). Anyone who can
reach it can register, replace and delete tools and tool classes. Allow
POST, PUT and DELETE only from trusted clients, at the ingress controller
(`trs_filer.ingress.annotations`), the OpenShift router
(`trs_filer.route.annotations`) or a proxy in front of them; see "Ingress
and Route" in the chart's README.
{{- if not (or .Values.trs_filer.ingress.enabled $route) }}

Nothing exposes the app: neither an Ingress (`trs_filer.ingress.enabled`)
nor an OpenShift Route (`trs_filer.route.enabled`, on clusters that serve
Routes) is created. Expose the app's Service
(`{{ .Values.trs_filer.appName }}`, port 8080) yourself. To try the API
from your machine meanwhile:

  kubectl port-forward svc/{{ .Values.trs_filer.appName }} 8080:8080 -n {{ .Release.Namespace }}

and open http://localhost:8080/ga4gh/trs/v2/ui

Once deployed:

  1. Access the API via {{ $scheme }}://{{ .Values.host_name }}/ga4gh/trs/v2/

       curl -X GET "{{ $scheme }}://{{ .Values.host_name }}/ga4gh/trs/v2/service-info" -H "Accept: application/json"

  2. Access the Swagger UI via {{ $scheme }}://{{ .Values.host_name }}/ga4gh/trs/v2/ui
